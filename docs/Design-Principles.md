# Design principles

1. **Quiet by default.** The interface should create space for memories, not compete with them.
2. **One clear next step.** Each screen should make the primary action obvious.
3. **Moments over administration.** Capturing an experience should feel lighter than managing data.
4. **Personal, not performative.** This is a private journal first, not a social feed.
5. **Earn complexity.** New capabilities arrive only when the core journey is already excellent.
