# Product principles

1. **Memories are primary.** Planning exists only to make capturing and remembering a trip better.
2. **Private by default.** A journal is intimate. Ownership and access control are product features.
3. **Presence before capture.** Recording must never pull the user away from the experience.
4. **One meaningful next action.** Each surface has a clear purpose and avoids dashboard clutter.
5. **Emotion over administration.** Use human language and visual storytelling, not database vocabulary.
6. **AI assists; the person authors.** Generated writing is editable, attributable, and never silently overwrites memories.
7. **Longevity is a requirement.** Data must remain understandable, exportable, and useful decades later.
8. **Complexity must be earned.** Do not build speculative interfaces or infrastructure without a concrete need.
9. **Calm in every state.** Empty, loading, error, and offline states deserve the same care as the happy path.
10. **Quality is end-to-end.** A feature is complete only when its UX, data model, security, accessibility, and failure modes are complete.

## Feature questions

Before implementation: Why does this exist? Can it be simpler? Can it be warmer? Does it protect the memory? Will it still feel right in five years?
