# Roadmap

## Foundation — now

- Next.js, TypeScript, and Tailwind CSS
- Supabase client foundation
- Vercel-ready configuration
- Minimal home screen

## Travel journal MVP — next

1. Create a trip
2. Add moments with text and photos
3. Generate a story from those moments
4. Show visited places on a map
5. Produce a final trip book

Advanced life-management features are intentionally outside the current scope.
